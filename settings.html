Hanya domain yang terdaftar di bawah ini yang diizinkan untuk melakukan operasi Export dan Import cookie.

Format: nama domain (misal: example.com) atau wildcard subdomain (misal: *.example.com).

Backup & Restore Konfigurasi

Simpan cadangan daftar domain whitelist Anda atau pulihkan dari file JSON konfigurasi sebelumnya.

Backup Konfigurasi

Unduh seluruh daftar domain whitelist yang tersimpan di browser ke dalam file JSON lokal.

Restore Konfigurasi

Pulihkan daftar domain whitelist dari file backup JSON yang sebelumnya telah Anda simpan.

Prinsip Keamanan Ekstensi

  • Ekstensi ini bekerja 100% di sisi browser lokal (Client-side). Tidak ada cookie atau data apapun yang dikirim ke server luar.
  • Whitelist domain mencegah ekspor dan impor tanpa sengaja pada situs yang tidak Anda kelola.
  • Hanya gunakan fitur import/export cookie pada environment development, testing, atau domain staging milik Anda sendiri.
